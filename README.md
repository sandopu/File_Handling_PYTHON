## Overview
This project is a Python-based file handling application that demonstrates core concepts of file management using Object-Oriented Programming (OOP). 
It allows users to create, read, overwrite, and manage duplicate files with proper error handling.

## Features
- Create new files with custom names and extensions
- Write content to files
- Read file content
- Overwrite files if they already exist
- Automatically create duplicate files when needed
- Handles file-related errors safely
- Uses inheritance for code reusability

## Concepts Used
- File Handling
- Exception Handling
- Inheritance
- String Manipulation
- User Input Handling

## Technologies Used
- Language: Python
- Programming Style: Object-Oriented Programming
- Platform: Windows / Cross-platform

## How to Run
1. Install Python (version 3.x)
2. Clone the repository:
   git clone <repository-link>
3. Open the project folder:
   cd <project-folder>
4. Run the program:
   python filename.py

## Use Case
This project is helpful for beginners who want to understand how file operations work in real-world Python applications.
